What changes when you follow the money?

Compared individual transaction data with network relationships across 203,769 Bitcoin transactions to investigate which potentially illicit activity an analyst should review first.

Finding Graph features improved average precision by 24% relative to a limited-feature baseline. Later-period degradation showed why ongoing evaluation matters.
