FEATURED RESEARCH · GRAPH MACHINE LEARNING

FraudGraph

Can a Bitcoin transaction look different once you see its network?

An independent research investigation using 203,769 Bitcoin transactions to compare transaction-only and graph-enhanced models, test analyst review limits, and examine what happens when performance changes over time.

Finding For named-feature XGBoost, test Average Precision increased from 0.4239 to 0.5240 with graph context. But later-period performance declined sharply—an important limitation, not a hidden result.

Python · NetworkX · XGBoost · React · TypeScript

Anfield Matchday Intelligence

A sold-out stadium. An unused ticket. Someone still trying to get in.

I explored unused tickets and supporter access across 38 home matches in two Premier League seasons, then built an interactive website connecting the findings to matchday decisions.

Finding The simpler forecast was stronger on held-out matches: historical-average MAE of 437 tickets versus 454 for Ridge regression.
