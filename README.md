# Franklin Osualaaham — Personal Portfolio

A responsive portfolio built using plain HTML, CSS and a little JavaScript. No paid builder, Node.js dependencies, or backend required.

## Preview locally

Open `index.html` in a browser, or from this folder run:

```bash
python -m http.server 8000
```

Then open http://localhost:8000.

## Deploy to Vercel

1. Create a **new public GitHub repository** (for example, `portfolio`).
2. Upload the *contents* of this folder to the root of that repository: `index.html`, `styles.css`, `script.js`, `assets/`, and `README.md`.
3. In Vercel, choose **Add New → Project → Import Git Repository** and select your repository.
4. Framework preset: **Other**. Build command: **leave empty**. Output directory: **leave empty** (root). Deploy.
5. Vercel will provide a live `*.vercel.app` URL. Add that URL to the Portfolio label in your resume only after testing it.

## Alternative: GitHub Pages

In the GitHub repository, choose **Settings → Pages → Deploy from a branch**, branch `main`, directory `/ (root)`.

## Customization checklist

- Replace the email address if it changes.
- Add your personal LinkedIn profile URL in the header/footer once you confirm it. No guessed profile URL was inserted.
- Replace the PDF in `assets/` when you update your resume.
- Add project cards only after you have results and a case study to share. Current class and capstone projects are mentioned accurately as in progress.
- The SVG network, stadium and charts are original conceptual visuals; they are not real screenshots of the projects. Consider replacing them later with carefully cropped screenshots from the apps.
- Statistics reflect your existing verified portfolio claims. Metrics are explanatory and are not assertions of production deployment or realized value.
